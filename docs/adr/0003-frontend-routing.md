# 3. Роутинг фронтенда: react-router в declarative mode

Дата: 2026-10-30
Статус: Принято

## Контекст

Главная страница должна вести на страницу записи; впереди ещё минимум
страница бронирования (выбор типа встречи и слота) и список предстоящих
встреч владельца. Нужны настоящие URL-страницы, а не переключение по
состоянию.

## Решение

- [react-router](https://reactrouter.com/) в declarative mode: пакет
  `react-router`, импорты `BrowserRouter`, `Routes`, `Route`, `Link`
  из `"react-router"` (отдельный пакет `react-router-dom` больше не нужен).
- Роутер объявляется в `src/main.tsx` (`BrowserRouter`), маршруты в
  `src/App.tsx`, компоненты страниц в `src/pages/`.

Альтернативы: переключение страниц по состоянию (нет URL, нет ссылок,
не масштабируется) и multi-page сборка Vite (дублирует HTML-входы, сложнее
делить состояние). Declarative mode выбран как минимально достаточный:
data-режим react-router (loaders/actions) пока не нужен.

## Последствия

- Vite dev-сервер сам отдаёт `index.html` для произвольных путей (SPA
  fallback), поэтому `/book` открывается напрямую.
- В компонентных тестах роутер подменяется на `MemoryRouter` внутри общей
  обёртки `renderWithProviders` (`src/test-utils.tsx`).
- При деплое хостинг должен уметь SPA fallback (переписывать все пути на
  `index.html`).
