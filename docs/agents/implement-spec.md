# Процедура реализации спецификации (implement-spec)

Рабочая процедура, по которой реализована текущая спецификация
([docs/spec.md](../spec.md); трекер-зеркало — issue #2 в исходном
проекте 386): от контракта до деплоя, одна функция за один цикл.
История применения — тикеты #3–#8 в 386 и коммиты ссылками `(#N)` в main.

## Цикл на один тикет (вертикальный срез)

1. **Контракт.** Правка `contracts/*.tsp` (модели, маршруты, коды ошибок).
2. **Генерация.** `npm run gen` → обновляются `contracts/tsp-output/openapi.yaml`
   и `apps/frontend/src/api-client` (коммитятся).
3. **Сервер (TDD).** Сначала тесты API по спецификации (happy path, ошибки
   данных, конфликты) — красный прогон; затем реализация маршрутов по
   контракту — зелёный. Правила бронирования живут только на сервере.
4. **Интерфейс.** Страница работает через сгенерированный SDK (рукописные
   `fetch` запрещены). Ошибки API показываются пользователю человеческим
   текстом (ветка `error` клиента).
5. **Проверки.** `mise run check` (линтер, форматы, типы, тесты, сборка,
   повторная генерация без diff, браузерный e2e против настоящих серверов).
6. **Коммит и тикет.** `feat: ... (#N)`, тикет закрывается комментарием с sha.

## Проверка защищённости тестов (мутационная)

Для правил бронирования минимум одно правило проверяется «на прочность»:
в отдельной рабочей копии (`git worktree`) правило временно нарушается,
защищающий тест обязан упасть (красный прогон), затем правило
восстанавливается — тест зелёный. Оба вывода и объяснение записываются
в тикет. Пример: тикет #5 в исходном проекте 386, правило «пересечение
интервалов запрещено, включая частичное наложение разных типов».

## Ревью

Перед пушем — независимая проверка агентами-ревьюерами: код-ревью, поиск
тихих сбоев, adversarial-верификация отчёта (все claims перезапускаются
командами). Перед пушем — secret_scanner.

## Порядок правки контракта

Любое изменение API: `contracts/*.tsp` → `npm run gen` → код обеих сторон.
Править сгенерированные `contracts/tsp-output/` и
`apps/frontend/src/api-client/` руками запрещено.
